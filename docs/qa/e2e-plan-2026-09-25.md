# End-to-end test plan — 2026-09-25

Deep testing of the product **from the UI**, against the dev server on :3000 and the real
development database. Two instruments, deliberately: the founder's real Chrome (the Claude
extension, signed in as the founder) drives the journey a consultant actually sees, one surface at
a time; headless Playwright drivers run in parallel for breadth, one per area, each owning a
disjoint slice of the code so fixes cannot collide. Every finding is fixed on the fly by the owner
of that slice or routed to whoever owns it; nothing is marked passed on inspection.

Status legend: ☐ not run · ✅ passed · ❌ failed (issue linked) · 🔧 fixed and re-run · ⏭ blocked

## Areas and owners

| Area | Owner | Files the owner may edit |

Rule: a finding outside your slice is **reported, not fixed**. The main session routes it.
